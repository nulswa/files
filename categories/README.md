# Categories

Here you can enter the category you want to browse to see the results. 
Each one has its own organized structure to avoid mixing files and getting confused.

## Available categories:
- **`thumb`** : Contains 5 subfolders to choose from.
- **`gif`** : Contains several subfolders with gifs, each organized in a specific order.
- **`game`** : Contains several subfolders with json files that can be applied to other projects.
- **`gacha`** : Contains 3 subfolders, each with json files and their specific use.

These files are intended to add functionality to *KronBot*, but they can also be useful for you if you use them.
